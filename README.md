# MG4
## Devlog
### In my game, I use the FloatAnimation script to make the fish food move up and down. The Start() method sets up the animation when the game begins. The Update() method runs every frame and controls the movement of the food. The _up variable is a boolean that determines the direction. When _up is true, the food moves up. When _up is false, the food moves down. The _timer variable tracks time and helps decide when to change direction. By repeating this process, the script makes the fish food float up and down.
